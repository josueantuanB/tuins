Política de privacidad

Última actualización: 23 de noviembre de 2026

En resumen

Este sitio no te pide datos personales. No tiene formularios ni cuentas de usuario, no usa cookies y no incluye herramientas de analítica ni de publicidad.

Recursos externos

Las tipografías, las imágenes y los estilos se cargan desde este mismo sitio. No se hacen peticiones a servicios de terceros.

Alojamiento

El sitio está alojado en GitHub Pages, un servicio de GitHub. Como cualquier servidor web, GitHub registra datos técnicos de cada visita, entre ellos la dirección IP, por motivos de seguridad. Tuins no tiene acceso a esos registros. Puedes leer más en la Declaración de privacidad de GitHub.

Alcance

Esta política cubre únicamente este sitio web, no la app Tuins.

Cambios y contacto

Si esta política cambia, publicaremos aquí la nueva versión con su fecha. Para cualquier duda, escríbenos desde la página de contacto.
